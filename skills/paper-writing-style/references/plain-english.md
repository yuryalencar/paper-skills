# Plain English substitutions and confusable words

The premise: a text is not more effective for using rarer words. Simpler and more direct
wording carries the idea faster, which is the whole objective. Deconstruct the instinct
that sophisticated vocabulary signals rigour.

## Imprecise nouns

Replace `fact` and `case` with what they actually stand for:

| Vague | Precise |
| :--- | :--- |
| this fact is related to | this effect is related to |
| this fact can be explained by | this observation can be explained by |
| this fact suggests | this phenomenon suggests |
| in this case the value was | the measured value was |

## Confusable words

| Words | Distinction |
| :--- | :--- |
| `analysis` / `analyses` | `analysis` is singular, `analyses` is plural. `Thermal analyses were carried out` and `the infrared analysis was performed` are both correct |
| `through` / `thorough` / `though` | `through` = by means of; `thorough` = complete, done with care; `though` = however, nevertheless. Spell-checkers substitute one for another silently |
| `increase` / `enhance` / `improve` | `increase` = becomes greater in number, size, or degree. `enhance` = adds value to something already good. `improve` = raises something from not good to good |
| `administer` / `administrate` | A drug or substance is *administered*. A company is *administrated*. Portuguese has one verb for both |
| `reproducible` / `reproductive` | Results are `reproducible`. `Reproductive` concerns reproduction |
| `data` | Treat as plural: `the data show`. Consistent plural use avoids every argument |
| `affect` / `effect` | `affect` is the verb, `effect` the noun, except `to effect a change` |
| `comprise` / `compose` | The whole comprises the parts; the parts compose the whole |

## Structure, not just vocabulary

The most common defect in non-native scientific English is a sentence built with
Portuguese structure and English words. Think and structure in English from the start.

Successive improvement of one sentence:

1. `The method for of diagnosis employed for determination of tumor of breast was the
   immunoassay ELISA.` Portuguese structure, too many articles and prepositions.
2. `The diagnosis method used for breast cancer detection was the ELISA immunoassay.`
   Word order now English.
3. `ELISA immunoassay was used to diagnose breast cancer.` Action moved into the verb.
4. `Breast cancer was diagnosed by ELISA.` Anyone in the field knows ELISA is an
   immunoassay, so saying so is redundant. This one is ready for a paper.

Two Portuguese habits worth checking for specifically: `thus` and `in this context`,
which carry over from `assim` and `dessa forma`. Delete them and reread. The sentence is
almost always better.

## Corpus tools

When unsure which preposition follows a verb, or whether a phrase is idiomatic in
published English, check a corpus of real scientific text rather than guessing:

- COCA, `english-corpora.org` (formerly `corpus.byu.edu`)
- Springer Exemplar

Both return passages from real publications with full references, which settles verb plus
preposition questions quickly.
